# Budget Builder Quest v1.1.0

## What's new

- **New game version.** Choose a life, build a full monthly budget, then live with it for **5 months of real-life curveballs**. Your checking, emergency fund, credit card, and fees change every month.
- **Money Health Score** for your budget plan, your choices, and where you ended up.
- **Looks like a real app.** Black launch screen with the big logo, new launcher icon, solid app bar, and About / Privacy / Credits panels.
- **Back button works.** Steps back from the budget, asks before leaving a quest, and asks before exiting.
- Still **100% offline**: no internet permission, no ads, no analytics, no accounts.

## Important: uninstall the old version first

This release is signed with a new key, so it can't install over v1.0.0 or v1.0.1. Uninstall the old app first. The app saves nothing, so nothing is lost.
