# Budget Builder Quest v2.0.0

Works on phones and tablets, in portrait and landscape. Like earlier versions, it works offline, with no ads, analytics, trackers, or account.

## Changes
- Version 2.0.0 (versionCode 200).
- The APK file is now named `WGRALGO-BudgetBuilderQuest-v2.0.0.apk`. All WGRALGO apps now use the same `WGRALGO-<AppName>-v<version>.apk` naming.
- The app is no longer locked to portrait. It now rotates with your phone or tablet, like the other WGRALGO apps.
- On phones turned sideways, the logo on the start screen is smaller, so the game starts on screen instead of below the logo.
- No changes to the questions, scoring, privacy, or license.

## Install
- **Have v1.1.0?** Install v2.0.0 straight over it. It's signed with the same key.
- **Have v1.0.0 or v1.0.1?** Uninstall it first. Those versions used an older signing key, so Android won't install over them.

Download `WGRALGO-BudgetBuilderQuest-v2.0.0.apk`, allow installs from unknown sources, and install it.
